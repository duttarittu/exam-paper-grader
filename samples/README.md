# Samples

Put sample exam papers here (PDF or JPG) for testing transcription and
grading at each step.

**This repo is public.** Do not add real student papers with real names
or roll numbers. Either:
- use papers with names/rolls blacked out or replaced with placeholders
  (e.g. "Test Student", "Roll 001"), or
- use your own handwriting as a stand-in.

For each sample, also add a short ground-truth note (what it actually
says) so transcription accuracy can be checked against it — e.g.
`sample1.jpg` + `sample1.expected.md`.
